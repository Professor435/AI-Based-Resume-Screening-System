# AI-Based-Resume-Screening-System
AI-Based Resume Screening System

I've created a comprehensive, fully functional AI-Based Resume Screening System with the following advanced features:
🎨 Design Features
Modern Glassmorphism UI with gradient accents (purple/pink theme)
Dark/Light mode toggle with persistent storage
Smooth animations including floating elements, hover effects, and transitions
Fully responsive design for all screen sizes
Interactive elements with micro-interactions
⚡ Core Functionality
1. Dashboard
Real-time statistics cards with animated counters
Activity feed showing recent actions
Quick action buttons for common tasks
Dynamic updates as data changes
2. AI Resume Upload
Drag & drop file upload zone with visual feedback
Simulated AI processing with progress bar and terminal-style logs
Job requirements configuration (title, experience, skills, description)
File parsing results with match scores
Add processed resumes to candidate pool
3. Candidate Management
Advanced filtering: Search by name/skills, match score slider, experience level, skills checkboxes, status filters
Sorting options: By score, experience, date, or name
View toggle: List vs Grid view
Status management: New, Reviewed, Shortlisted, Rejected
Bulk comparison: Select up to 3 candidates for side-by-side comparison
4. Candidate Profiles
Detailed modal view with full information
AI analysis section showing strengths and gaps
Skills visualization
Education and experience details
Match score breakdown (Technical, Culture Fit)
Interview scheduling button
5. Analytics Dashboard
4 Interactive Charts using Chart.js:
Match Score Distribution (Bar chart)
Skills Demand (Doughnut chart)
Processing Time Trends (Line chart)
Source Effectiveness (Bar chart)
Real-time data updates
6. Settings
AI algorithm selection
Match threshold configuration
Notification preferences
Data management options
🚀 Interactive Features
Simulated AI Processing: When you upload files, it shows realistic processing steps with typing effects
Dynamic Data: 25 sample candidates generated with realistic profiles
Real-time Search: Instant filtering as you type
Comparison Tool: Compare multiple candidates side-by-side
Status Updates: Change candidate status with dropdown
Toast Notifications: Success/error messages for actions
💾 Data Persistence
Theme preference saved to localStorage
All candidate data managed in memory (simulated database)
File upload handling with simulated parsing
To use this system:
Save the code as an .html file
Open in any modern browser
Navigate through sections using the top menu
Upload files (simulated) in the Upload section
Filter and sort candidates in the Candidates section
Click on candidates to see detailed AI analysis
Select multiple candidates and click "Compare Now" for side-by-side comparison
The system demonstrates a production-ready AI resume screening workflow with beautiful, modern UI and complete interactivity!
